Laipni lūdzam **Bobby's Picerija** virtuālajā vadības centrā! 🌟 Šī nav tikai parasta programma – tā ir pilna servisa picērijas simulatora sistēma, kas apvieno **klientu psiholoģiju**, **loģistiku** un **finanšu uzskaiti** vienā jaudīgā Java Swing aplikācijā. 🎮💼

---

## 🔥 Kāpēc šis projekts ir unikāls?

Šī sistēma tika izstrādāta, lai maksimāli pietuvinātu lietotāju reālai darba videi, izmantojot modernus programmēšanas paņēmienus:

* **🎭 Reālistiska Simulācija:** Klienti nav vienkārši teksta rindas – tie ir objekti ar savu raksturu, vārdu un unikālām vēlmēm! 🧐
* **⚡ Dinamiskā Interaktivitāte:** Programma reaģē uz lietotāja ievadi reāllaikā. Ja pieļausi kļūdu pasūtījumā – klients Tevi palabos! 🗣️❌
* **📈 Biznesa Loģika:** Iebūvēta kases sistēma, kas automātiski aprēķina peļņu, pievieno piegādes maksas un pārvalda pasūtījumu rindu (`Queue` datu struktūra). 💸📊
* **🎬 Vizuālais Baudījums:** Aplikācija nav "sausa" – tā ir piepildīta ar GIF animācijām un vizuāliem tēliem, kas rada dzīvas picērijas atmosfēru. 📺✨

---

## 🛠️ Tehnoloģiskais Stack & Arhitektūra

Projekts balstās uz **tīru kodu** un **modulāru uzbūvi**, sadalot atbildību starp specializētām klasēm:



### 🏗️ Klašu Struktūra:

| Klase | 🔍 Uzdevums & Maģija |
| :--- | :--- |
| 🧠 **GalvenaKlase** | Sistēmas "smadzenes". Kontrolē spēles gaitu, loģiku un lēmumu pieņemšanu. |
| 🖼️ **GUI** | Vizuālā saskarne. Rūpējas par to, lai viss izskatītos izcili un lietotājam draudzīgi. |
| 👤 **Klients** | Klientu ģenerators. Izmanto nejaušības algoritmus, lai katra vizīte būtu unikāla. |
| 🍕 **Pica** | Virtuālā virtuve. Aprēķina cenas bāzējoties uz sastāvdaļu izvēli un izmēriem. |
| 💾 **SaglabatFaila** | Atmiņas modulis. Nodrošina, ka neviens pasūtījums netiek pazaudēts un viss tiek fiksēts vēsturē. |
| ✍️ **Darbnieks** | Dialogu meistars. Animē tekstu, padarot sarunu ar klientu dabisku. |

## 🎮 Spēles Gaita (Gameplay)

Sajūties kā īsts vadītājs:

1.  **🔓 Atver Maiņu:** Ienāc sistēmā un sagatavojies klientu plūsmai. 🚪
2.  **🛎️ Apkalpo Klientus:** Izmanto **R-Keeper** termināli. Uzmanīgi klausies klienta teiktajā un precīzi ievadi datus. 📝
    * *Padoms:* Ja klients saka "Havajas pica", neievadi "Margarita" – bizness tā nestrādā! 🍍🚫
3.  **🚚 Piegāde vai Uz Vietas:** Atšķirīgi scenāriji atkarībā no pasūtījuma veida. Zvaniet kurjeram, ja nepieciešams! 📞🛵
4.  **💰 Iekasē Naudu:** Pabeidz pasūtījumu un skaties, kā kase pildās ar eiro. 💶🔥
5.  **📜 Analizē Vēsturi:** Darba dienas beigās apskati savu sniegumu sadaļā "Vēsture". 📖✅
